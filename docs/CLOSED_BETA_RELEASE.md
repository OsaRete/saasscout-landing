## Weekly delivery and capacity

Delivery is the persisted, owner-visible in-app report. The scheduler reads Weekly-enabled profiles in UUID order with keyset pagination and rotates the first candidate one position each UTC week. With a stable candidate list every owner eventually takes the first position. Same-period replay uses the same order for an unchanged list. The authoritative service checks current Beta admission before claiming or generating. Owner-period claims prevent overlapping generation, and each paid dispatch needs its own durable reservation and one-use claim. A completed run is reused. An exhausted owner or shared budget fails closed. Discovery/Scan usage and unresolved transport failures can leave no capacity for Weekly. Rotation does not reserve money or guarantee a report. Monitor aggregate run duration against the Vercel function limit and limit the initial cohort to verified capacity.
